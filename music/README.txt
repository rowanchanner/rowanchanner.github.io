Sharky Wrapped music
====================
Drop MP3 files in this folder named 1.mp3, 2.mp3, 3.mp3 ... (up to 8.mp3).
Wrapped picks one at random each time it plays. No files = no music
(everything else still works).

Only use music you have the rights to (royalty-free / licensed for
websites). Copyrighted songs can get the site taken down.
Keep each file under ~10 MB so it loads fast on phones.
